# New Year Surprise 2027

Персональная новогодняя открытка на чистых HTML, CSS и JavaScript. Подходит для GitHub Pages.

## Файлы
- `index.html` — разметка и анкета
- `style.css` — оформление и анимации
- `script.js` — персонализация, фото в браузере, повторный просмотр, поделиться и оригинальная мелодия на Web Audio

## Публикация через GitHub Pages
1. Создай новый публичный репозиторий, например `new-year-surprise`.
2. Загрузи в корень репозитория `index.html`, `style.css`, `script.js` и папку `assets`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Подожди завершения публикации. GitHub покажет адрес сайта в разделе Pages.

## Важное о фото и данных
- Анкета не отправляется на сервер и не сохраняется в базе.
- Фото выбирается локально, отображается через временный URL браузера и не загружается в GitHub.
- При перезагрузке страницы персональная сцена сбрасывается.
- Не проси одноклассников загружать чужие фотографии без разрешения.
- Сайт использует Google Fonts через интернет; при отсутствии сети будут системные шрифты.

## Ограничения текущей версии
Выбор стиля меняет цветовую атмосферу CSS-сцены, но не создаёт отдельную фотореалистичную AI-картинку. Все эффекты и оригинальная синтезированная мелодия работают без API и дополнительных сервисов. Музыка запускается только после нажатия кнопки пользователем.
